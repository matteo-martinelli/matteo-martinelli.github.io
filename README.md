## Tools list

### Retrieve articles information online: 
- (SerpAPI)[https://serpapi.com/google-scholar-api]: to query Google Scholar using a REST call and receive structured data (e.g., title, author, citations, links, author profile ...). It requires a registration and an API key.
- (SearchAPI.io)[https://www.searchapi.io/google-scholar]: similar to SerpAPI, allows very granular queries.
- (Apify)[https://apify.com/api/google-scholar-api]: exposes a GScholar scraper, which returns exportable data in JSON and other formats. 
- (Scrapeless, Scrapingdog, Scrapfly)[https://scrapfly.io/blog/posts/google-scholar-api-and-alternatives]: other API based services.
- ... alternatively: use ORCID (look (here)[https://info.orcid.org/register-a-client-application-production-member-api/]).
